# 修复记录：Android CI JDK 11 与 foojay-resolver 1.0.0 不兼容（2026-11-08）

## 失败信息
- 仓库：wiseism/MyAndroidApp
- Workflow：Android CI
- 失败 run：[42336305256](https://github.com/wiseism/MyAndroidApp/actions/runs/42336305256)（2026-11-07）

## 错误日志摘录
```
Could not resolve org.gradle.toolchains:foojay-resolver:1.0.0
- Variant 'shadowRuntimeElements' declares a component compatible with Java 17
  and the consumer needed a component compatible with Java 11
```

## 原因分析
`settings.gradle` 插件 `org.gradle.toolchains.foojay-resolver-convention 1.0.0`
只提供 Java 17 的构件，而 workflow 用 JDK 11 启动 Gradle；
同时 Gradle wrapper 已是 9.3.1（本身要求 JDK 17+），JDK 11 无法运行。

## 修复内容
`.github/workflows/android.yml`：`set up JDK 11` → `set up JDK 17`（temurin）。
